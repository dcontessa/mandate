# Dependencies and attribution

Mandate uses the provided Sites Vinext starter and its installation/build helpers, React, TypeScript, Vinext, Cloudflare Workers/D1/R2 bindings, Drizzle migrations, shadcn/Radix UI, Lucide icons, Tailwind CSS, Sonner, Zod and Terminal 3 SDK. Exact versions are in the two lockfiles. Original third-party packages and bundled primitives retain their upstream licences.

The Terminal 3 Node adapter follows the official authentication sequence, checked 7 September 2026:
https://docs.terminal3.io/developers/adk/get-started/quickstart

Architecture boundaries also draw on:
https://docs.terminal3.io/developers/adk/overview/agent-auth-adk
https://blog.terminal3.io/the-agentic-ai-security-governance-manifesto/

The manifesto is a provider product statement, not evidence that this implementation possesses every listed control. No source from it is represented as independent security assurance.

Synthetic data and PDF fixtures were created for this project. UBT/APAD documents, older MandateAI drafts, confidential reports and private Notion exports are not included. This source contains a curated account of the agreed product decisions only.
