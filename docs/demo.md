## Two-person flow after deployment

Configure a trusted sign-in deployment, D1 and R2. Sign in as preparer and explicitly create a synthetic sandbox. This creates an isolated copy; there is no public reset operation.

Invite a reviewer’s email and share the returned link yourself. No email is sent by Mandate. The reviewer signs in with that email in a separate browser/account, accepts once, opens the source PDF, establishes source authority, opens the exact package and recipient, and approves. The preparer refreshes, checks the Release tab and records an internal sandbox receipt. Refresh again: the receipt persists. Attempting the same request retrieves the existing receipt.

For a blocked case, before recording a successful receipt, approve v1, then select v2 and press **Use this version for review** as preparer. Attempt a sandbox record: the server rejects the changed snapshot and records the block. Change back or obtain a fresh review. Completed requests are frozen; the current prototype supports one secretarial release request per owned sandbox.
